# PackWares CMS Documentation

Welcome to the comprehensive documentation for **PackWares CMS** - your complete guide to managing customers, deals, quotations, costing, and system settings.

## Quick Start

Use the sidebar on the left to navigate through different topics and tutorials. Each guide includes step-by-step instructions with screenshots to help you get the most out of PackWares CMS.

## What's Covered

### Core Features
- **Customer Management** - Create and manage customer profiles
- **Deals** - Track and manage sales opportunities
- **Request Costing** - Submit costing requests
- **Quotations** - Generate and update quotations
- **Costing Completion** - Complete costing workflows

### Configuration & Formulas
- **Formulas** - Create and manage calculation formulas
- **Variables** - Define and use variables in calculations
- **Constants** - Set up constant values
- **Flute Pickup Factor** - Configure flute pickup factors

### System Management
- **Videos** - Manage video content
- **Tickets** - Handle support tickets

### Settings
- **Profile Information** - Update your profile
- **Referral System** - Manage referrals
- **Team Management** - Organize your team
- **User Roles** - Configure user permissions
- **Unit of Measure (UOM)** - Set up measurement units
- **Naming Conventions** - Customize naming patterns
- **Paper Grade** - Manage paper grade settings
