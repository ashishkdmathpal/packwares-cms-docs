# 2.Deals

## # [Packwares CMS](https://cms.packwares.com/manufacturer/deals)

### 1. Click on New Deal

Creating a new deal.

![Step 1 screenshot](./images/2.deals/2.deals-step-01.png)

### 2. Type "Deal or Project Name"
![Step 2 screenshot](./images/2.deals/2.deals-step-02.png)

### 3. Select Customer Name from Dropdown

You need to ensure that the customer is already created else no data will be shown here.

![Step 3 screenshot](./images/2.deals/2.deals-step-03.png)

### 4. Enter Qty "15000"
![Step 4 screenshot](./images/2.deals/2.deals-step-04.png)

### 5. Optional Type "Remarks related to the project"
![Step 5 screenshot](./images/2.deals/2.deals-step-05.png)

### 6. Select Design Type

You can customize this.

![Step 6 screenshot](./images/2.deals/2.deals-step-06.png)

### 7. Enter Dimensions
![Step 7 screenshot](./images/2.deals/2.deals-step-07.png)

### 8. This is output

The value are calculated based on the Formula used as show on left side. You can also customize the formula.

![Step 8 screenshot](./images/2.deals/2.deals-step-08.png)

### 9. Select correct Unit of Measure

mm is default

![Step 9 screenshot](./images/2.deals/2.deals-step-09.png)

### 10. Select Dimension Type…

Select as per your process.

![Step 10 screenshot](./images/2.deals/2.deals-step-10.png)

### 11. Select as per the requirement

Or go with default value.

![Step 11 screenshot](./images/2.deals/2.deals-step-11.png)

### 12. Select number of ply
![Step 12 screenshot](./images/2.deals/2.deals-step-12.png)

### 13. Select Brown-200-35-12.0

These are pre-filled and can be customized

![Step 13 screenshot](./images/2.deals/2.deals-step-13.png)

### 14. Select B-FLUTE (1.35)

These are pre-filled and can be customized

![Step 14 screenshot](./images/2.deals/2.deals-step-14.png)

### 15. Click on Semi Auto
![Step 15 screenshot](./images/2.deals/2.deals-step-15.png)

### 16. Enter Bursting Strength

Optional

![Step 16 screenshot](./images/2.deals/2.deals-step-16.png)

### 17. All Board Specifications…

These are calculated based on your inputs.

![Step 17 screenshot](./images/2.deals/2.deals-step-17.png)

### 18. Click on Save Costing

Once you are done with all the entries then save as draft.

![Step 18 screenshot](./images/2.deals/2.deals-step-18.png)

### 19. Click on Back to list

to close this window

![Step 19 screenshot](./images/2.deals/2.deals-step-19.png)

### 20. New Deal or Project is created 

You can future view or edit this deal.
