# PackWares CMS Documentation

Welcome to the comprehensive documentation for **PackWares CMS** - your complete guide to managing customers, deals, quotations, costing, and system settings.

## Quick Start

PackWares CMS is a unified platform for corrugated box manufacturers and sourcing teams. This documentation will help you master every feature of the system.

> **New to PackWares?** Start with [Customer Management](/docs/customer) to learn how to create and manage customer profiles.

## Documentation Sections

### Core Features

Essential features for day-to-day operations:

- **[Customer Management](/docs/customer)** - Create and manage customer profiles with contact details, business terms, and credit limits
- **[Deals](/docs/deals)** - Track sales opportunities and customer inquiries
- **[Request Costing](/docs/request-costing)** - Request cost calculations for box specifications
- **[Quotation Generate](/docs/quotation-generate)** - Create professional quotations for customers
- **[Quotation Update](/docs/quotation-update)** - Modify and manage existing quotations
- **[Costing Complete](/docs/costing-complete)** - Finalize cost calculations and pricing

### Configuration & Formulas

Advanced configuration for customizing calculations:

- **[Formulas](/docs/formula)** - Configure custom calculation formulas
- **[Variables](/docs/variables)** - Define and manage calculation variables
- **[Constants](/docs/constants)** - Set system-wide constant values
- **[Flute Pickup Factor](/docs/flute-pickup-factor)** - Configure flute specifications

### System Management

Tools and utilities:

- **[Videos](/docs/videos)** - Video tutorials and guides
- **[Tickets](/docs/tickets)** - Support ticket system

### Settings

Personalize and configure your account:

- **[Profile Information](/docs/settings-profile)** - Manage your profile details
- **[Referral System](/docs/settings-referral)** - Access your referral program
- **[Team Management](/docs/settings-team)** - Manage team members and permissions
- **[User Roles](/docs/settings-user-roles)** - Configure user roles and access levels
- **[Unit of Measure (UOM)](/docs/settings-uom)** - Define measurement units
- **[Naming Convention](/docs/settings-naming-convention)** - Set naming standards
- **[Paper Grade](/docs/settings-paper-grade)** - Configure paper grade specifications
