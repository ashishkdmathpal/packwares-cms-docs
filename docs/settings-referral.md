# Referral system in Packwares CMS

Earn credits through referrals and use the app for free.



## # [Packwares CMS](https://cms.packwares.com/settings/referrals)

### 1. Click on Setting > Referrals
![Step 1 screenshot](./images/14.settingsreferral/14.settingsreferral-step-01.png)

### 2. Check if you already have a referral code 
![Step 2 screenshot](./images/14.settingsreferral/14.settingsreferral-step-02.png)

### 3. Else click on Generate Referral Code
![Step 3 screenshot](./images/14.settingsreferral/14.settingsreferral-step-03.png)

### 4. You can now see your referral code 
![Step 4 screenshot](./images/14.settingsreferral/14.settingsreferral-step-04.png)

### 5. Click on Copy Link and share in your network
![Step 5 screenshot](./images/14.settingsreferral/14.settingsreferral-step-05.png)

### 6. How Referrals work
![Step 6 screenshot](./images/14.settingsreferral/14.settingsreferral-step-06.png)
