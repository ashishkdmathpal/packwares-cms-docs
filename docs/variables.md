# Variables: Update + Create + Delete in Packwares CMS

## # [Packwares CMS](https://cms.packwares.com/formula-master/formulas)

### 1. Click on Formula Master
![Step 1 screenshot](./images/8.variables/8.variables-step-01.png)

### 2. Click on 📊 Variables Tab

The number 4 indicates the total number of variables.

![Step 2 screenshot](./images/8.variables/8.variables-step-02.png)

### 3. View all existing Variables
![Step 3 screenshot](./images/8.variables/8.variables-step-03.png)

### 4. Click on pencil icon to edit Variables
![Step 4 screenshot](./images/8.variables/8.variables-step-04.png)

### 5. Update the values
![Step 5 screenshot](./images/8.variables/8.variables-step-05.png)

### 6. Click on Update to save
![Step 6 screenshot](./images/8.variables/8.variables-step-06.png)

## # Create New Variable
You can also create new variables of your choice

### 7. Click on Add Variable
![Step 7 screenshot](./images/8.variables/8.variables-step-07.png)

### 8. Update all the fields

Symbol, Default value, Description and Unit of measure

![Step 8 screenshot](./images/8.variables/8.variables-step-08.png)

### 9. Click on Create
![Step 9 screenshot](./images/8.variables/8.variables-step-09.png)

### 10. You can view the variable at the bottom.
![Step 10 screenshot](./images/8.variables/8.variables-step-10.png)

### 11. You can similarly delete any variable
![Step 11 screenshot](./images/8.variables/8.variables-step-11.png)

### 12. Click on Delete
![Step 12 screenshot](./images/8.variables/8.variables-step-12.png)

### 13. This is the final list of variable
